# Audit: Worthwatch web UI, 2026-11-03

This audit ran against a seeded copy at 127.0.0.1:7788 in headless Chrome, on all 14 routes. It covered 1280×800, 390×844 and 768×1024 (with touch), in dark and light. Touch was emulated, and Safari (WebKit) was not tested.

| # | Dimension | Score | Key finding |
|---|---|---|---|
| 1 | Accessibility | 1 | 39% (dark) and 43% (light) of 1,454 text nodes fail AA, mostly because of `--text-3`. The palette has no focus trap. Live updates move focus on Check-in. |
| 2 | Performance | 3 | One 348 KB JS chunk (122 KB gzip) and 81 KB of fonts. No route splitting. uPlot is built twice on mount. |
| 3 | Theming | 3 | Only 3 hard-coded colours. Light accent, positive and negative fail AA on surfaces. |
| 4 | Responsive | 2 | At 768px the Check-in name column collapses to 0px and Budget overflows by 101px. Budget chart text renders at 4.2px on a phone. |
| 5 | Implementation integrity | 1 | ⌘⇧H blur is broken. Enter in the palette saves a check-in. `.btn` is defined in 10 places in 3 styles. |
| | **Total** | **10/20** | **Acceptable** |

## P0

**Privacy blur does not blur**
- **Where:** `ui/src/App.svelte:41` sets `<svelte:body class:blur>`. Svelte 5 never applies it, so `.blur .money` in `ui/src/tokens.css:61` never matches.
- **Exposure:** amounts stay readable on Home (20), Changes (62), Account (50), Exposure (32, plus 31 `title`s), Look-through (24), Check-in (12), Portfolio (12) and Overlap (7, plus 6 `title`s).
- **Fix:** toggle the class in an `$effect`, blur the `title` and `aria-label` amounts too, and add an e2e test.
- **Command:** `/impeccable harden`

## P1

**Enter in the palette saves the check-in**
- **Where:** `ui/src/screens/CheckIn.svelte:100-103`. A window keydown listener saves on Enter in any INPUT, including the palette input.
- **Fix:** scope the listener to the form and ignore events where `defaultPrevented` is set.

**Live SSE updates move focus**
- **Where:** `ui/src/screens/CheckIn.svelte:46`. The `$effect` refocuses the first field on every view update.
- **Fix:** focus once, on mount.

**`--text-3` contrast**
- **Where:** `ui/src/tokens.css:11`, `:42` and `:52`.
- **Measured:** dark 3.23 / 3.03 / 2.80 and light 2.63 / 2.82 / 2.43, on bg / surface / surface-2.
- **Also:** placeholders (`#757575` default) measure 3.53–4.06.
- **Command:** `/impeccable colorize`

**Light-theme semantic colours fail AA**
- **Where:** `ui/src/tokens.css:43-44` and `:53-54`.
- **Measured on bg / surface / surface-2:**
  - accent: 3.74 / 4.01 / 3.45
  - positive: 4.08 / 4.37 / 3.76
  - negative: 4.34 / 4.65 / 4.00
- **Also:** the Save button label measures 3.74, the treemap selected name 1.74, and treemap % labels 2.45–2.71.

**Command palette accessibility**
- **Where:** `ui/src/lib/components/Palette.svelte:62-92`.
- **Problems:**
  - Tab leaves the `aria-modal` dialog.
  - Esc works only from the input.
  - Focus is not restored on close.
  - The listbox contains `div` sections.
  - `aria-activedescendant` points at a missing id when there are no hits.

**768px layouts break**
- **Where:**
  - `ui/src/screens/CheckIn.svelte:212`: the name column collapses to 0 and the page overflows by 35px.
  - `ui/src/screens/Budget.svelte:344-345`: overflows by 101px.
- **Command:** `/impeccable adapt`

## P2

- **Charts lack a text alternative and keyboard access:**
  - `ui/src/lib/charts/NetWorthChart.svelte:189`
  - `ui/src/lib/charts/FanChart.svelte:73`
  - `ui/src/lib/charts/RunningTotal.svelte:31`
  - `ui/src/lib/charts/Bridge.svelte:44`
- **SVG text scales too small:** Budget's RunningTotal renders at 4.2px on a phone, and Changes' Bridge at 7.2–8.6px everywhere.
- **Hover-only tips on touch:** FanChart and RunningTotal. Also, RunningTotal's caption says "hover a day".
- **Treemap targets** (`ui/src/lib/charts/Treemap.svelte:82`): 203 tab stops, and 178 targets under 24px at 390px wide.
- **Clickable or stateful elements with no ARIA:**
  - `<tr onclick>` rows at `ui/src/screens/Portfolio.svelte:106` and `ui/src/screens/LookThrough.svelte:64`
  - no `aria-pressed` on the segmented controls
  - no `aria-current` in `ui/src/lib/components/Rail.svelte`
  - unlabelled Check-in date input
  - `display:none` file input in `ui/src/lib/components/ImportPanel.svelte`
- **Page structure:** no h1 on most screens, a static `document.title`, and few live regions.
- **Touch targets:** most are under 44px at 390px, and the phone rail hides 10 of 17 items.
- **Phone layouts:**
  - The Budget category select is hidden.
  - Check-in unit and price inputs are clipped at 62px.
  - Chat uses `100vh` instead of `dvh`.
- **Drift:**
  - 18 radius values, 20 font sizes, 24 gap values and 69 padding values.
  - `.btn` defined in 10 files and `.link` in 8; segmented controls built 6 times.
  - The Chat focus ring measures 2.82:1 in light.

## P3

- The light-theme block is duplicated in `ui/src/tokens.css:38-48` and `:49-56`.
- Performance:
  - All screens are imported eagerly.
  - NetWorthChart builds twice (`ui/src/lib/charts/NetWorthChart.svelte:149-165`).
  - There is no font preload.

## Positives

- Token discipline is good, with only 3 hard-coded colours.
- Every tab stop shows a visible focus ring.
- Dark-theme body text passes AA.
- There is no horizontal overflow at 390px wide.
- uPlot handles touch well.
- Pages are lean and have no animation.
- The detector found 1 issue in `ui/src`, a `side-tab` at `LookThrough.svelte:161`. It is a false positive: a selected-row marker, not a decorative stripe.
