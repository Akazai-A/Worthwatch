# Worthwatch documentation

Start with [Get started](use/getting-started.md). Each page below covers one task. The folders match the sections: `use/`, `run/` and `develop/`.

## Use Worthwatch

- [Get started](use/getting-started.md): install, load sample data, and do your first check-in.
- [User guide](use/user-guide.md): what each screen shows and how to use it.
- [Budget your spending](use/budgeting.md): import bank statements, set limits, sort categories, track bills.
- [Play the budget game](use/budget-game.md): beat a daily allowance, fill a jar to your monthly goal, and play weekly challenge cards.
- [Set up the Apple Pay feed](use/apple-pay-feed.md): send each Wallet purchase from your iPhone as you pay.
- [Configure Worthwatch](use/configuration.md): settings in `ledger.yaml` and environment variables.
- [Prices, FX and fund holdings](use/data-sources.md): where the numbers come from and how to override them.

## Connect and run

- [Connect an AI assistant](run/mcp.md): use Worthwatch from Claude Desktop, Claude Code or another MCP client.
- [Keep Worthwatch secure](run/security.md): the recommended setup, a checklist, and the risk that's left.
- [Access Worthwatch remotely](run/remote-access.md): reach it from your phone or another computer, safely.
- [Back up and restore](run/backup-restore.md): keep your data safe and move it to a new machine.
- [Run Worthwatch on a Mac](run/macos.md): start it at login on a Mac mini with launchd.
